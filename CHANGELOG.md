# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [1.0.0] - 2025-01-24

### Added
- Song data model (JSON format) for chord chart storage
- HTML/CSS template system matching TNBGJ songbook format
- Chord transposition utility with bluegrass spelling conventions
- HTML generator (song JSON to reviewable HTML)
- PDF generator (HTML to landscape letter PDF via Puppeteer)
- Claude Code skill for automated chord chart creation
- Sample song: Angeline the Baker (Key of D)
